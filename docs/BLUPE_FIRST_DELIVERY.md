## 首轮演示范围

单臂从桌面抓起一个刚性、非易碎物，放入固定托盘/目标区域，释放后撤离并验证结果。物体优先选择平台现成且有尺寸信息的方块或瓶子；cup 是现有 mock 配置，不代表对方现场已摆放。

演示体现：图像理解目标 → 检索物体抓取经验 → 检查邻居/工作区约束 → 固定 IK 抓放技能 → 重新观察验证 → 保存可追溯运行记录。无把握时明确停止。

首轮成功后再加受保护邻居和两个物体的顺序清理。CLIP 全面升级、四类关系图、完整 VLABench 恢复与大规模实验不是本轮对接前置。

## 必需代码与验收

1. **感知定位**：把物体身份和像素区域接入现有 VLM 客户端。位置必须有几何依据：可用且通过质量检查的配对深度，或标定 K/T 加经测量支撑面/物体高度。缺少几何依据不能用 VLM 的直接米制猜测驱动真机。固定 top 相机与对应标定，记录时间戳和来源。
2. **任务到动作**：使用同一坐标系内的目标与目的地；检索卡片参数实际进入夹爪开度、接近方向等可执行项。YAM 不支持的 force/synergy 参数要明确标注，不能当作已执行。
3. **运动预检**：验证站点就绪、关节与工具坐标、工作区、桌面净空、非操作臂位置、预算和首步连续性。当前关节插值测试不能代替碰撞验证。
4. **最小闭环**：执行成功回执后重新观察；确认指定位置、保护物不变、已释放和撤离。当前新增 verifier 已覆盖错放/保护物缺失/回执拒绝，但单帧位置通过不证明稳定释放。恢复初版允许有界重新观察与重新规划；无法判明抓持状态时停止，避免盲目重复 pick。
5. **可交接运行包**：独立安装说明、真实配置与示例配置分离、固定任务入口、只读预检入口、离线测试、回执/图像/视频及一次运行说明。对接方式（由我们运行客户端还是平台托管）待对方确认，不先假定需要网页或部署服务。

交付状态分开记录：离线可运行、只读接口通、仿真/规划验证、真机一次任务完成、供他人试用。前一项不能替代后一项。
