# 可见性重规划：实现与独立验证协议

日期：2026-11-03。r5 和 r6 的冻结数据不变。本轮改进任务级观察/规划流程。

## 已观察到的问题

r6 的 18 例中，三组均为 5/6。seed 700 的上层黄色物体已经识别，
下层只露出边缘，VLM 及有界复核仍返回 unknown。原运行时要求所有待操作目标
立即可见，因此动作前停止。该失败保留，不改写成绩。

## 新行为

- 任务必须明确允许改变子目标顺序；受保护物体必须全部可见。
- 从已保存的公开 RGB-D 候选和上层物体的已知高度建立匿名支撑见证。
  需要同一新观测、二维投影重叠、XY 距离小于 26 mm、支撑高度差小于 5 mm。
- 只选择本来就在任务中的、已经识别、低脆弱性、未被其他支撑约束阻挡的上层目标，
  移到既有目标区。不能抓取匿名物体、添加臆造身份、删除待完成目标或移动保护物。
- 该重排占用原运行时最多三次的重规划预算。原始模型输出保持 unknown，
  匿名支撑不会被称为某个缺失目标。
- 任务重排工具的结果送给实际 VLM 审核；VLM 拒绝时仍停止。
  搬移后必须重新获取真实 RGB-D 和模型身份结果，再处理下层目标。
- 默认关闭；有序任务、无支撑见证、保护物不可见、预算耗尽时保持停止行为。

这不是开放语言任务分解：三个子目标和目的地仍由任务显式给出。
本轮验证的是部分可见条件下的安全顺序调整和重新观察。

## 验证

1. 已知 seed 700 独立回归，不计入新种子成绩。核对首次 RGB-D、四个候选、
   提示词及原始回答与原失败案例相同，保留旧失败视频和新完整视频。
2. 冻结新种子 800–809 的 20 个配对 rollout，均为堆叠布局。
   两组使用相同场景、真实 Qwen/CLIP、检索、记忆、身份复核、试提和接触求解。
   仅可见性重规划开关不同，不注入错误或刻意设置失败。
3. 录制预先声明的 800、805；所有失败保留。报告触发次数、任务完成数、
   模型调用和双方完成案例的配对效率。若新种子未触发该问题，不宣称新功能提高完成率。
4. 审计重排见证来自原始感知回执、所选目标已经模型识别、保护物可见、
   原始待办目标未被跳过。物理成功仍使用原阈值独立判断。

## 展示修正

回放页现在按实际调节时间显示电机力上限，不把最终调整后的数值提前显示。
预防性留存验收未通过也不再被文字描述成已经发生滑脱。
任务重排说明只在相应观测之后出现，原始视频不剪改。
